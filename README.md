# 读心术-纸牌魔术

纯前端 3D 纸牌魔术网页：完整魔术秀（洗牌切牌展扇开场 →「27 张牌读心术」压轴 → 谢幕）。零依赖、无构建、离线可玩。

## 运行

双击打开 `index.html` 即可（支持 `file://` 协议）。

也可以起一个本地静态服务器：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

## 部署（GitHub Pages 子路径）

本项目所有资源均为相对路径（`css/`、`js/`），可直接部署到仓库子路径，例如 `https://<user>.github.io/<repo>/`：

```bash
git init && git add . && git commit -m "magic show"
# 推送到 GitHub 后：Settings → Pages → Deploy from branch → 选择分支根目录
```

无需任何构建步骤。

## 魔术原理（不是作弊）

- **27 张读心术**：每轮按行发成 3 列，你指认牌所在列后，那一列被真实地夹进正中间。三轮之后数学上保证你的牌必然位于整叠正中间（数组下标 13，第 14 张）。你可以自由记任何一张牌。
- **防穿帮**：所有动画严格按真实牌堆数据执行（收牌顺序 = 数组顺序），动画不会改变魔术的真实结果。

## 测试

```bash
npm test        # 即 node test/tricks.test.cjs
```

覆盖：27 个初始位置 × 27 种三轮指认组合的穷举验证（诚实指认全部收敛到 13；"指错列"作为非法输入单独统计）、5000 次随机洗牌收敛、牌组完整性。

## 交互

- 点击 / 空格 / 回车：继续
- 数字键 1 / 2 / 3 或点击列：选列
- 顶栏：音效开关、速度（悠闲/标准/快速）、重新开始（3 秒内二次确认）

## 已知边界

- 观众故意指错列时魔术会"失败"——这与现实中指错列砸场一致，揭晓后可点"再来一次"。
- 动画期间快速点击"重新开始"会安全中断当前流程（token 机制），不会破坏状态。
- `prefers-reduced-motion` 下动画自动缩短；音效设置存于 localStorage。
